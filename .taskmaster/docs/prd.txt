# 產品需求文件 (PRD)
# 慈濟災害個人資料收集系統 - 前端整合後端 AI 圖片分析服務

## 專案概述

**專案名稱**：慈濟災害個人資料收集系統 v0.0.5（地端驗證版）
**專案目標**：將後端 AI 圖片分析服務整合到現有前端 UI/UX 中
**目標用戶**：災區工作人員（一般用戶）
**專案期程**：5.5 天

## 背景

本專案已有完整的申請表單 UI/UX（Next.js + React + HeroUI），包含：
- 步驟 1: 慰問信
- 步驟 2: 授權同意書
- 步驟 3: 申請表單（4 個子步驟：基本資料 → 證件照片 → 電子簽名 → 確認送出）
- 步驟 4: 完成頁面

後端團隊已完成 Supabase Self-hosted AI 處理服務架構，包含：
- image_analyses 資料表（含 EXIF、AI 分析結果、向量 embedding）
- disaster-images Storage bucket
- process-image Edge Function（OpenAI Vision API）
- Database Trigger（自動觸發處理佇列）
- Realtime 即時推送

前端現有服務模組存在問題：
- imageAnalysisService.ts 和 useRealtimeImageAnalyses.ts 有 UTF-8 編碼問題
- 型別定義需對照後端 Database Schema 更新
- 需整合 EXIF 解析到 CameraCapture 組件
- 需整合圖片上傳服務到 handleFinalSubmit 函數
- 需加入 Realtime 狀態顯示 UI

### 5. 整合圖片上傳服務（P4）

#### 5.1 在 handleFinalSubmit 中整合圖片上傳
- **檔案**：heroui/app/application/new/page.tsx
- **整合位置**：handleFinalSubmit 函數（子步驟 4：確認送出）
- **整合內容**：
  ```typescript
  import { uploadAndProcessImage } from '@/services/imageAnalysisService'
  import { subscribeToProcessingStatus } from '@/hooks/useRealtimeImageAnalyses'

  const handleFinalSubmit = async () => {
    // 上傳身分證正面
    const frontIdResult = await uploadAndProcessImage(
      fileData.frontIdPhoto!,
      '身分證正面照'
    )

    // 訂閱處理狀態
    const unsubscribe = subscribeToProcessingStatus(
      frontIdResult.analysisId,
      (status, data) => {
        if (status === 'completed') {
          console.log('AI 分析完成:', data.caption, data.tags)
        }
      }
    )

    // 等待處理完成（60 秒超時）
    await waitForCompletion(frontIdResult.analysisId, 60000)

    // 上傳其他照片...
    // 繼續原有邏輯...
  }
  ```
- **驗收標準**：可成功上傳所有照片，觸發 AI 分析，接收 Realtime 更新

### 7. 完整流程測試（P6）

- **測試案例**：

## 技術架構

### 前端技術棧
- Next.js 15.3.1 (App Router)
- React 18.3.1 (Client Components)
- TypeScript 5.6.3
- HeroUI 2.8.4
- Tailwind CSS 4.1.11

### 後端技術棧
- Supabase Self-hosted (Docker)
- PostgreSQL + pgvector
- Supabase Auth
- Supabase Storage
- Supabase Edge Functions
- OpenAI Vision API

### 整合架構
```
CameraCapture (EXIF 解析)
  → app/application/new/page.tsx (handleFinalSubmit)
    → imageAnalysisService (上傳 Storage + 寫入 DB)
      → Supabase (Database Trigger)
        → Edge Function (AI 分析)
          → Realtime 推送
            → useRealtimeImageAnalyses (狀態更新)
              → UI 顯示結果
```

## 前後端職責劃分

### 前端職責（寫入 image_analyses）
- user_id, tenant_id
- image_name, image_url, thumbnail_key
- event_description
- exif_datetime, exif_gps, exif_camera, exif_raw
- status='pending'（觸發 Database Trigger）

### 後端職責（Edge Function 更新）
- caption, tags
- caption_embedding, tags_embedding
- status='completed' | 'failed'
- error_message

## 非功能需求

### 效能需求
- 圖片上傳：< 5 秒（10MB 檔案）
- AI 分析：< 30 秒（一般情況）
- Realtime 延遲：< 2 秒

### 可靠性需求
- 網路中斷：自動重試 3 次
- AI 分析失敗：不阻塞申請流程，允許繼續
- Realtime 超時：60 秒超時提示

### 相容性需求
- 支援圖片格式：JPG, PNG, HEIC, HEIF
- 檔案大小限制：50MB
- 瀏覽器支援：Chrome, Safari, Firefox 最新版
