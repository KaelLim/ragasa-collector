# 暫停重評習慣機制 v1.0

## 🛑 **強制暫停觸發條件**

### **⏰ 時間基礎觸發**
```
【30 分鐘間隔檢查】
- 每 30 分鐘自動觸發暫停重評
- 檢查當前工作是否偏離原始目標
- 評估是否需要調整方向

【2 小時深度檢查】
- 每 2 小時進行深度暫停重評
- 重新檢視整體架構方向
- 確認是否陷入過度工程化

【一日工作結束檢查】
- 每個工作日結束前進行全面反思
- 總結當日是否遵循核心原則
- 記錄違反原則的情況和學習
```

### **🚨 行為觸發條件**
```
【立即暫停信號】
✓ 連續 3 次基於假設進行開發決策
✓ 發現自己在解決「技術上有趣」而非「實際需要」的問題
✓ 開始實作前未能清楚解釋「為什麼需要」
✓ 超過 1 小時沒有可運行的測試驗證
✓ 開始因為技術困難而考慮改變需求

【警告暫停信號】
⚠ 使用了「應該」、「可能」、「通常」等不確定性詞彙
⚠ 開始查找替代方案而非解決原始問題
⚠ 感覺當前工作變得複雜但說不清必要性
⚠ 連續 20 分鐘沒有參考官方文檔
```

## 🤔 **標準化暫停重評流程**

### **📋 30 分鐘快速重評 (3-5 分鐘)**

```markdown
🛑 **暫停重評檢查點 - 30min**

⏰ 當前時間：_____
🎯 原始目標：_____

【快速評估】（每項 30 秒）
1. ✅/❌ 我當前在做的事情直接服務於原始目標嗎？
2. ✅/❌ 過去 30 分鐘的工作基於確定的文檔/需求嗎？
3. ✅/❌ 當前方向是最簡單有效的解決方案嗎？
4. ✅/❌ 我能在 10 秒內解釋為什麼當前工作是必要的嗎？

【決策】
□ 繼續當前工作（4 個 ✅）
□ 暫停並調整方向（任何 ❌）
□ 執行深度重評（超過 2 個 ❌）

【行動記錄】
決定：_____
理由：_____
下次檢查：_____
```

### **🔍 2 小時深度重評 (10-15 分鐘)**

```markdown
🛑 **深度暫停重評檢查點 - 2hr**

⏰ 當前時間：_____
🎯 原始目標：_____
📊 過去 2 小時工作摘要：_____

【深度分析】（每項 2-3 分鐘）

1. **目標一致性檢查**
   - 當前工作內容：_____
   - 與原始目標的關聯度：_____/10
   - 如果 <7，說明偏離原因：_____

2. **原則遵循檢查**
   - 無文件，不實作：過去 2hr 是否基於假設？_____
   - 實際測試優於文件：是否有可運行的驗證？_____
   - 架構思維：方案是否符合實際部署需求？_____

3. **複雜度評估**
   - 當前解決方案複雜度：簡單/適中/複雜
   - 是否存在更簡單的替代方案？_____
   - 複雜度的必要性說明：_____

4. **進度與價值評估**
   - 實際解決的問題：_____
   - 剩餘核心問題：_____
   - 當前方向的投資回報比：_____/10

【決策選項】
□ 繼續當前方向（高一致性 + 高價值）
□ 調整當前方向（中等偏離，可修正）
□ 重新規劃方案（嚴重偏離或低價值）
□ 暫停專案並諮詢（根本方向錯誤）

【行動計劃】
下一步行動：_____
預期成果：_____
驗證方法：_____
下次深度檢查：_____
```

## ⚙️ **自動化暫停提醒系統**

### **⏰ macOS 定時提醒腳本**

```bash
#!/bin/bash
# pause-reminder.sh - 自動暫停提醒系統

# 30 分鐘提醒
schedule_30min_reminder() {
    while true; do
        sleep 1800  # 30 分鐘
        osascript -e 'display notification "🛑 暫停重評：過去 30 分鐘工作是否偏離目標？" with title "CLAUDE 原則檢查"'
        
        # 檢查是否在 Claude Code 會話中
        if pgrep -f "claude" > /dev/null; then
            osascript -e 'display dialog "🛑 請執行 30 分鐘暫停重評檢查點" buttons {"已完成檢查"} default button 1'
        fi
    done
}

# 2 小時深度提醒
schedule_2hr_reminder() {
    while true; do
        sleep 7200  # 2 小時
        osascript -e 'display notification "🔍 深度重評：請執行 2 小時暫停重評檢查" with title "CLAUDE 深度檢查"'
        
        # 強制暫停所有開發活動
        osascript -e 'display dialog "🛑 強制暫停：請立即執行 2 小時深度重評" buttons {"開始重評"} default button 1'
    done
}

# 日終提醒
schedule_daily_reminder() {
    while true; do
        # 檢查是否到了工作日結束時間（下午 6 點）
        current_hour=$(date +"%H")
        if [ "$current_hour" -eq 18 ]; then
            osascript -e 'display notification "📅 日終重評：請執行今日工作總結與明日規劃" with title "CLAUDE 日終檢查"'
            sleep 3600  # 等待一小時避免重複提醒
        fi
        sleep 600  # 每 10 分鐘檢查一次
    done
}

# 並行執行所有提醒
schedule_30min_reminder &
schedule_2hr_reminder &
schedule_daily_reminder &

echo "✅ 暫停重評提醒系統已啟動"
wait
```

### **📱 Slack/Discord 集成提醒**

```javascript
// slack-reminder.js - 整合 Slack 提醒
const { WebClient } = require('@slack/web-api');

class PauseReminderBot {
    constructor(token, channel) {
        this.slack = new WebClient(token);
        this.channel = channel;
    }

    async send30MinReminder() {
        await this.slack.chat.postMessage({
            channel: this.channel,
            text: '🛑 暫停重評提醒',
            blocks: [
                {
                    type: 'section',
                    text: {
                        type: 'mrkdwn',
                        text: '*🛑 30 分鐘暫停重評檢查點*\n\n請暫停當前工作，執行快速重評：\n• 當前工作是否服務於原始目標？\n• 是否基於確定的文檔/需求？\n• 是否為最簡單有效的方案？'
                    }
                },
                {
                    type: 'actions',
                    elements: [
                        {
                            type: 'button',
                            text: { type: 'plain_text', text: '已完成檢查' },
                            action_id: 'pause_check_complete'
                        },
                        {
                            type: 'button',
                            text: { type: 'plain_text', text: '需要深度重評' },
                            action_id: 'need_deep_review'
                        }
                    ]
                }
            ]
        });
    }

    async send2HourReminder() {
        await this.slack.chat.postMessage({
            channel: this.channel,
            text: '🔍 深度重評提醒',
            blocks: [
                {
                    type: 'section',
                    text: {
                        type: 'mrkdwn',
                        text: '*🔍 2 小時深度暫停重評*\n\n⚠️ 強制暫停：請立即執行深度重評\n• 目標一致性檢查\n• 原則遵循檢查\n• 複雜度評估\n• 進度與價值評估'
                    }
                }
            ]
        });
    }

    startReminders() {
        // 30 分鐘間隔提醒
        setInterval(() => this.send30MinReminder(), 30 * 60 * 1000);
        
        // 2 小時間隔提醒
        setInterval(() => this.send2HourReminder(), 2 * 60 * 60 * 1000);
        
        console.log('✅ Slack 暫停重評提醒系統已啟動');
    }
}

// 使用範例
const reminder = new PauseReminderBot(
    process.env.SLACK_BOT_TOKEN,
    '#dev-reminders'
);
reminder.startReminders();
```

## 🔄 **重評結果行動框架**

### **📋 標準決策樹**

```
暫停重評結果 → 決策路徑

【繼續當前工作】
條件：目標一致 + 原則遵循 + 進度良好
行動：直接繼續，下次檢查照常

【微調當前方向】  
條件：輕微偏離但可修正
行動：調整實作細節，重新確認文檔

【重新規劃方案】
條件：明顯偏離或過度複雜
行動：停止當前工作，重新分析需求

【諮詢協作夥伴】
條件：根本方向不確定
行動：暫停專案，尋求外部意見
```
